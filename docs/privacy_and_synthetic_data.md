# Privacy and synthetic data / 隐私与合成数据

## English

- Every record is generated from code with a fixed random seed.
- The generator does not accept or read a confidential source dataset.
- Identifiers use newly designed fictional formats.
- Transaction types and business keys are generic demonstration concepts.
- No credentials, private network addresses, employer names, customer names, internal tables, or production mappings are required.
- The committed example is safe to regenerate locally without external services.

Before publishing, run the repository safety scan described in `docs/publish_checklist.md`.

## 中文

- 所有记录均由代码使用固定随机种子生成。
- 生成器不接收、不读取任何保密源数据。
- ID采用全新设计的虚构格式。
- 交易类型和业务键仅用于通用演示。
- 项目不需要凭据、内网地址、公司名称、客户名称、内部表名或生产Mapping。
- 示例可在本地离线重新生成，不依赖外部服务。
