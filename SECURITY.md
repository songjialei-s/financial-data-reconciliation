# Security and privacy

This repository is designed to run without credentials, external databases, APIs, shared drives, or private network access.

All committed business records are generated by `generate_data.py` from a fixed seed. Do not replace the synthetic files with employer, customer, marketplace-account, or production-system extracts.

Before publishing or contributing:

1. Do not commit `.env` files, credentials, private network addresses, local user paths, or database files.
2. Do not add real order, account, settlement, item, customer, or transaction identifiers.
3. Run the tests and the repository safety scan.
4. Review all staged files before every push.

If a secret is committed, revoke or rotate it before removing it from Git history.
